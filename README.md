# 樱之村物语 · Sakura Village Story

日式像素风 2D 俯视角田园 RPG 原型（参考星露谷物语）。纯 HTML5 Canvas，无依赖、无外部图片。

## 运行
直接双击 `index.html` 用浏览器打开即可。

**学校篇** —— 双击 `school.html`（旧的 `classroom.html` 会自动跳转过去）。
方向键 / WASD 移动，或用鼠标点击地面走过去；点击同学、黑板、门等会自动走到旁边并调查（也可以面对它按 E）。
走到教室下方的前门 / 后门就会进入走廊，走廊里 2-A 的两扇门可以回到教室。
四楼是四个功能性小房间（电脑室、实验室、校长室、教导主任办公室），共用 `smallrooms.js` 的模板，配置见 `SMALL_ROOMS`。
走廊两头都是楼梯：上半（亮）往上走，下半（暗）往下走，可以在一~四楼之间移动（三楼走廊是同一个模板 `buildHallway(楼层)`）。

进度会自动保存（存在浏览器的 localStorage 里）：刷新后回到上次的场景和位置；连按两次 **R** 清档从头开始（会回到选人界面）。

学校篇代码在 `js/school/`：
- `engine.js` — 通用引擎：输入、角色、寻路、对话、场景切换（淡入淡出）
- `props.js` — 共用家具美术
- `classroom.js` / `hallway.js` / `staffroom.js` / `smallrooms.js` — 各个场景（布局、NPC、出入口）
  - 六间教室（1-A ~ 3-B）共用 `classroom.js` 的同一个模板，差异写在 `CLASSES` 里；`open: true` 的才能进（现在只开放 2-A）
- `main.js` — 注册场景；新增场景就写一个 `buildXxx()` 并在这里登记

## 操作
| 按键 | 作用 |
|---|---|
| WASD / 方向键 | 移动（Shift 跑步） |
| 空格 / J | 使用手中道具（锄地、浇水、播种、收获） |
| E / Enter | 交谈、调查、开门、出货 |
| 1–8 / Q / Tab | 切换快捷栏 |
| Esc | 暂停 / 关闭菜单 |

## 玩法
1. 用锄头开垦栅栏内的草地 → 撒种 → 每天浇水（水壶空了去河边装水）
2. 浇过水的作物在夜里成长；芜菁 4 天、萝卜 6 天
3. 收获后放进家门口的出货箱，第二天早上结算；也可以直接卖给杂货铺
4. 回家门口睡觉进入下一天（自动存档）；超过凌晨 2 点会晕倒
5. 神社可以每天祈祷一次，恢复体力

## 代码结构
- `js/art.js` — 所有像素美术（字符画 + 程序化生成）
- `js/world.js` — 地图生成、碰撞、地面渲染、作物
- `js/main.js` — 输入、角色 / NPC、对话、商店、时间、昼夜、HUD、存档
- `js/font.js` — 内嵌的 Fusion Pixel 像素字体（SIL OFL，见 `assets/fonts/OFL.txt`）

内部分辨率 384×216，按整数倍放大到窗口，保证像素清晰。
